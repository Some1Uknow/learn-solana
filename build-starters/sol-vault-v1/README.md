# LearnSol SOL Vault

This workspace is intentionally small. You will implement one real Anchor program in five stages.

## Before you begin

Use Anchor `0.31.0` and a compatible Solana `2.1.x` toolchain. Then run:

```bash
anchor build
```

Your submission is exactly this file:

```text
target/deploy/sol_vault.so
```

Keep the declared program ID unchanged. The grader invokes that program ID directly.
