# Challenge 12: Immediate Or Cancel Buy

An IOC order executes immediately and cancels whatever cannot fill.

## Task

Implement `ioc_buy`.

## Rules

- Consume asks from lowest price to highest price.
- Track total base filled.
- Track total quote spent.
- Return leftover quantity as canceled.
- Do not insert leftover quantity into the book.

## Example

Trying to buy `8` base units against:

- `2` at `100`
- `3` at `105`

Only `5` units can fill:

```txt
filled = 5
spent = 2*100 + 3*105 = 515
canceled = 3
```
