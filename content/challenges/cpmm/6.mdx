# Challenge 6: Mutating Swap Reserves

Earlier challenges quoted output. Now mutate pool state.

## Task

Implement `apply_swap`.

## Rules

- Fee = 30 bps.
- Effective input = `x_in * 9_970 / 10_000`.
- `new_x = x + effective_input`
- `k = x * y`
- `new_y = k / new_x`

## Example

For `x = 1000`, `y = 2000`, `x_in = 100`:

- effective input = `99`
- `new_x = 1099`
- `k = 2_000_000`
- `new_y = 1_819`

Return:

```txt
1099 1819
```
