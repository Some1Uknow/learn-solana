# Challenge 17: Conservative Quote Rounding

In AMM math, rounding direction matters.

## Task

Implement `floor_output`.

## Requirement

Always round down.

That means:

```txt
floor(2000 / 11) = 181
```

## Why this matters

Rounding up user output can leak value from the pool over time.
