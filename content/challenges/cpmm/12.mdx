# Challenge 12: Proportional Deposit Quote

Liquidity should usually be added in the same ratio as the existing reserves.

## Task

Implement `required_y_deposit`.

## Formula

Use:

```txt
x_deposit * y_reserve / x_reserve
```

## Example

For:

- `x_reserve = 1000`
- `y_reserve = 2000`
- `x_deposit = 250`

Then:

```txt
250 * 2000 / 1000 = 500
```
